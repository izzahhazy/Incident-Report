Google Sheet connection
Every report you submit is written straight to your Google Sheet (tab "Incident Log"), so anyone using this same link sees the same records, and it survives closing the tab.

One-time setup:
1. Open a blank Google Sheet → Extensions → Apps Script
2. Copy all the code from the included file incident_apps_script.gs, paste it in, then Deploy → New deployment → Web app, "Who has access" = Anyone
3. Copy the deployment URL, paste it above, tap Save URL.
